# VAYU Privacy Notes

VAYU uses location only to show local AQI, weather, route support, and preventive safety guidance.

## Guest mode

If the user does not log in, profile and exposure tracker data stay in the browser localStorage.

## Logged-in mode

When backend login is used, VAYU syncs profile and exposure history to the backend database.

## Location

Browser location permission is required. The app cannot and should not bypass browser permission.

## Medical note

VAYU provides preventive guidance, not diagnosis or treatment.
